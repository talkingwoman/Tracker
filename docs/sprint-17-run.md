# Запуск и проверка Sprint 17

## Сборка

Откройте `Tracker.xcodeproj`, выберите схему Tracker и iPhone Simulator. Минимальная версия приложения — iOS 17.0. Проверки выполнялись в Xcode 26.1.1 / iOS Simulator 26.1.

Все зависимости подключены через Swift Package Manager:

- SnapshotTesting 1.19.5 — только тестовый target;
- AppMetrica 6.6.0, продукт AppMetricaCore;
- R.swift 7.8.0, RswiftLibrary и build plugin RswiftGenerateInternalResources.

При первом запросе Xcode разрешите **Trust & Enable** именно для R.swift. Он генерирует `R.generated.swift` в DerivedData перед компиляцией. Этот файл не нужно создавать вручную, переносить в проект или коммитить. Проверка плагинов глобально не отключается.

## Тесты

В Xcode: Product → Test (⌘U). Схема задаёт русский язык, регион RU и часовой пояс UTC для воспроизводимых скриншотов.

Из корня репозитория (имя симулятора должно быть установлено в вашей Xcode):

```sh
xcodebuild -project Tracker.xcodeproj -scheme Tracker \
  -destination 'platform=iOS Simulator,name=iPhone 16e,OS=26.1' \
  -derivedDataPath /tmp/TrackerSprint17Checks \
  CODE_SIGNING_ALLOWED=NO test
```

В наборе 33 теста, включая 19 скриншотов. Эталоны зависят от версии iOS: запуск на другой версии может выявить системные изменения шрифтов, эмоджи и UIKit. Не перезаписывайте эталоны автоматически при падении; сначала сравните изображения и проверьте причину.

Тесты загружают модель из bundle и создают отдельную in-memory базу. Хост приложения под XCTest не открывает пользовательскую SQLite. Тест миграции создаёт временную SQLite старой версии, мигрирует её и повторно открывает, проверяя название, эмоджи, цвет, расписание, категорию, UUID, отметку и закрепление.

Дополнительная проверка ресурсов и 30 случаев склонений ru/en/de/ar:

```sh
swiftc -module-cache-path /tmp/TrackerSwiftModules scripts/verify-localization.swift -o /tmp/verify-tracker-localization
/tmp/verify-tracker-localization /tmp/TrackerSprint17Checks/Build/Products/Debug-iphonesimulator/Tracker.app ru
```

Повторите последнюю команду с `en`, `de` и `ar`. Отдельный XCTest проверяет вызовы через сгенерированный R.swift API.

## AppMetrica: требуется собственный API key

SDK подключён, события Main формируются и проверяются тестом, но без ключа отправка отключена. Тестовый ключ не подставлялся.

В настройках приложения Tracker в AppMetrica скопируйте **API key приложения**, не пароль Яндекса и не OAuth-токен.

Для локального запуска в Xcode: Product → Scheme → Edit Scheme → Run → Arguments → Environment Variables. Добавьте `APPMETRICA_API_KEY` со своим ключом. Не сохраняйте ключ в общей схеме под Git.

Для запуска без Xcode создайте `Tracker/App/AnalyticsKeys.plist` (Property List) со строковым ключом `APIKey`. Папка App синхронизирована с target, файл будет ресурсом приложения. Этот путь исключён из Git. Ключ в клиентском bundle не является серверным секретом; пароль и персональный токен сюда помещать нельзя.

События по заданию:

| event | screen | item |
|---|---|---|
| open | Main | отсутствует |
| close | Main | отсутствует |
| click | Main | add_track / track / filter / edit / delete |

После подключения ключа откройте главный экран, нажмите добавление/отметку/фильтры, выберите редактирование и удаление в контекстном меню, перейдите в статистику. Проверьте приход событий в кабинете AppMetrica. Отмена удаления не удаляет данные; событие `delete` фиксирует выбор действия в меню. Автоматические тесты реальную аналитику не отправляют.

## Ручной контроль перед сдачей

- Создать привычку с расписанием, отметить её сегодня и в прошлом; в будущем отметка недоступна.
- Проверить сочетания поиска, даты и фильтров; кнопка фильтров остаётся при пустом результате поиска, если на день есть трекеры.
- Долгим нажатием открыть меню: закрепить, открепить, изменить название/расписание/цвет, отменить удаление и подтвердить удаление тестового трекера.
- При редактировании сохранить историю, при удалении убрать историю и обновить статистику.
- Перезапустить приложение, проверить сохранённые трекеры, отметки и закрепление.
- Проверить русский/английский интерфейс и светлую/тёмную тему. Пользовательские названия не переводятся.

Коммиты, push и сдача в Практикуме в рамках этой работы не выполняются автоматически.
